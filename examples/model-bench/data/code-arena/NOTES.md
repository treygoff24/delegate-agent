# Code Arena collection notes

- **What it measures:** Community pairwise preferences for coding outputs in Arena's Code Arena. The live `/leaderboard/code` table reports one aggregate Arena Score per model configuration, plus rank, confidence bounds, and battle count. Higher scores rank better.
- **Captured data:** Live leaderboard snapshot retrieved 2026-09-23 01:18:33 UTC; the page's vote cutoff is 2026-09-22T16:00:00Z. The page reported 130 model entries and 735,398 total votes. There is no separately numbered benchmark release; this is the current live snapshot.
- **Collection method:** Saved the JavaScript-rendered page to `raw/code-arena/leaderboard-code.html`, then extracted its embedded full-precision entries, cutoff, vote total, and model total into `raw/code-arena/live-code-arena-data.json`. The page snapshot exposes all 130 entries. Official Hugging Face `lmarena-ai/leaderboard-dataset` files and README are also retained in `raw/`; records in its `webdev/latest` split show leaderboard date 2026-09-11, older than the live cutoff, so that split was not used for current scores. The saved Hugging Face README documents dataset schema and CC BY 4.0 licensing.
- **Metrics:** `arena_score` is the page's published score/rating, retained at full precision. `n` is the page's battle/vote count. `ci` is the exact half-width of the interval formed by the page's lower and upper confidence bounds; because the shared schema stores only a symmetric half-width, the exact bounds remain in the raw JSON. `measured_on` uses the date portion of the page's vote cutoff. Explicit effort labels are copied from model names when they identify a level; harness is recorded when the model key says `codex-harness`.
- **Rows and model configurations:** 130 rows for 130 listed model configurations, one `arena_score` metric row each. Two entries had no publisher organization in the source and use `unknown/` IDs. `subset` is `overall`, matching the aggregate table represented by this route. The page lists provider price-per-million-token information, but it is not an Arena evaluation cost paired with the score; the shared per-task cost fields are therefore null. No time metric is published.
- **Caveats:** Scores are community preference estimates from pairwise battles, not executable coding-task success rates. Battle counts vary substantially; low-count and marked preliminary entries have greater uncertainty. One source entry (`mimo-v2.6-pro`) is unranked and marked AutoEval, but its score, interval, and embedded vote count are retained as published. Models and their configurations may change over time. Arena's live page offers no redistribution terms directly; the official dataset README states CC BY 4.0, recorded on each row. No contamination audit or independent reproduction was provided by the benchmark.
- **Not captured:** Historical scores and separate WebDev/Image-to-WebDev surfaces are not part of the current `/leaderboard/code` table snapshot. Cost and latency as evaluation metrics are not published.
