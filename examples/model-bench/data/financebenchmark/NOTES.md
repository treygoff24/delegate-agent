# FinanceBenchmark collection notes

- **What it measures:** FinanceBenchmark publishes a weighted FB Score index over its tracked evaluations, alongside model scores for individual benchmarks. Its methodology describes financial verification, document QA, forensic reasoning, numerical reasoning, and agent tasks; the tracked suite also includes broader non-finance tests.
- **Version and date:** Methodology version 1.2 (last updated June 2026). The live site says its leaderboard was updated **2026-09-15**; captured on 2026-09-22 (America/New_York). Row retrieval timestamps are UTC. Detail-page run dates are generally shown only as `YYYY-MM`, so `measured_on` is null where a complete day is unavailable.
- **Collection:** Captured the homepage, model catalog, benchmark directory, methodology, model-data JavaScript asset, all 41 linked benchmark detail pages, and the PAVE repository leaderboard Markdown in `raw/financebenchmark/`. The homepage full table supplies composite FB Scores. Individual benchmark detail tables supply underlying scores; the site PAVE page also reports levels 1–4; the separately captured repository leaderboard contributes its own records. No paired cost, time, confidence interval, sample count, or reasoning-effort settings were published in these captured tables.
- **Rows:** 683 score rows across 45 distinct model IDs: 41 composite FB Score rows, 623 underlying website benchmark rows, and 19 additional PAVE repository leaderboard values (seven model rows across the numeric columns present). 36 of 41 detail pages had scored result tables. Five pages (bankertoolbench, big-finance-bench, gdpval-mm, gdpval-rubrics, prbench-finance) showed a header-only results table, zero evaluated models, and a 0.0%/N/A summary; no model rows were emitted for them. The homepage table lists 42 models; GLM-5.5 has no numeric composite score and is omitted from rows. The 41 numeric composite rows therefore cover 41 distinct model IDs. Model configurations recur across subsets; no reasoning-effort variants were distinguished.
- **Metrics:** `fb_score` is the site's weighted composite index (higher is better). Individual result tables label the score `Overall`; these are recorded as `overall` under the page's benchmark slug subset. PAVE also has `level_1` through `level_4`. The separately published PAVE repository table uses `average_score`, `fabv2_vals_ai`, `finben`, and `cfa_level_iii`; its `Average Score` combines its available evaluations. Its `Pave (Interchange)` and `Time/Run` cells are dashes for every listed model and were not emitted. Values are copied as displayed in percentage points, with unit `%`; no rescaling was applied.
- **Caveats:** The publisher says scores are attributed to original benchmark papers or FinanceBenchmark-run evaluations, and its methodology says its own runs follow the original scoring protocol. The FB Score normalizes weights over only the benchmarks a model has completed, so coverage differs. The homepage/model catalog repeat some component metrics and disagree with benchmark-specific tables (for example, Claude Opus 4.7's FinQA value is 81.0 on the homepage and 84.0 on the FinQA results page). To avoid duplicate conflicting rows, underlying benchmark values here use each benchmark's own results page; homepage component columns and model-catalog component columns were not separately added. Benchmark detail source dates are sometimes older than the Sep 15 platform update; these are the dates presented on the source rows. The PAVE repository table has no per-row dates and was last updated July 11, 2026 per the repository listing, so those separate rows may be stale relative to the Sep 15 site update. The website does not provide a contamination assessment.
- **License / redistribution:** No data license or redistribution license was stated on the captured site or methodology page. The methodology says each score is attributed to its original source; attribution is preserved in row notes where shown. Redistribution terms remain unspecified.
- **Not captured:** The five listed benchmark pages exposed empty result tables, not model scores. No standalone CSV or JSON score file was linked from the captured pages; the rendered HTML, model-data asset, and raw PAVE repository leaderboard are preserved for audit.
