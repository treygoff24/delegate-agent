# TerminalWorld collection notes

- **What it measures:** AI agents completing terminal and command-line workflows derived from real developer recordings. The leaderboard uses the manually reviewed TerminalWorld-Verified subset: 200 tasks, evaluated with the Terminus-2 scaffold and Harbor harness.
- **Data version/date:** TerminalWorld-Verified, 200 tasks. Leaderboard says “Updated May 21, 2026”; all eight listed model configurations use the default reasoning/thinking effort. Captured 2026-09-23 UTC (2026-09-22 EDT).
- **Collection method:** Saved the rendered leaderboard HTML and each of its eight linked model detail pages under `examples/model-bench/raw/terminalworld/`. The leaderboard page was retrieved directly with `curl`; its model links were followed with `curl`. The linked GitHub `LEADERBOARD.md` was attempted but returned 404; Hugging Face contains the task dataset, not leaderboard result records. The current page HTML is therefore the result source.
- **Metrics:** `pass_rate` is the published percent passing (and its row carries the paired total API cost for the full 200-task run and average task time); cost basis is one full evaluation run. `cost_per_pass` is the source’s rounded dollar cost per successful task. `avg_turns` is source-reported average number of LLM API calls per task. The page reports average time in minutes; `time_s` converts that displayed value to seconds (minutes × 60). No separate wall-clock leaderboard metric is listed in the main table.
- **Coverage/count:** 8 model configurations × 3 standalone metrics = 24 rows. Each model’s pass rate, total cost, per-pass cost, average turns, and average time were checked against its detail page. There is one row for each effort configuration shown; all use default effort, with no separately named effort values.
- **Caveats:** The source describes these as API costs based on public model pricing; costs are not independently reproduced. Detail pages provide per-task outcomes, but source methodology and potential training contamination are not independently verified here. The site describes sandboxed tasks and task-specific canary identifiers as anti-cheating safeguards; these do not establish absence of contamination. The leaderboard is dated May 21, 2026, so entries may be stale as of retrieval. Manifest metadata says `reports_time: false`, but linked detail pages visibly report average time; captured as paired `time_s` and the discrepancy is retained here. Values labelled per-pass and average turns/time follow the detail page display and rounding.
- **License:** The dataset/site state CC-BY-4.0. Hugging Face dataset card also declares `cc-by-4.0`; this capture records the stated terms and attribution should be preserved.
- **Not captured:** No model effort variants or additional leaderboard subsets/configurations were listed. The site’s GitHub leaderboard markdown link returned 404; only rendered leaderboard and detail-page data were available.
