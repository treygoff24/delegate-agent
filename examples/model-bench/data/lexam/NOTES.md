# LEXam results capture

- **What it measures:** Legal reasoning on law-school examination questions from 340 exams. The benchmark includes long-form open questions and multiple-choice questions; the dataset card describes English and German material and exam questions from 2016–2022.
- **Captured data date:** The leaderboard page does not give a per-row date. The Hugging Face dataset card says results on open questions were updated in 2025/09 using an ensemble LLM-as-a-Judge. The dataset repository metadata was last modified 2026-05-21, but that is not a dated leaderboard refresh. `data_date` is therefore unknown at day precision.
- **Retrieval:** Downloaded the official LEXam website HTML on 2026-09-23 UTC; the two leaderboard tables are embedded in that page. Also saved the current Hugging Face README and API metadata, GitHub repository API metadata, and `LICENSE_DATA`. The page references `data/results/model_scores.js` and `output_folders.js`, but both URLs return 404, so the HTML table is the available primary score source. The tables contain 36 open-question entries and 31 multiple-choice entries, represented by 67 rows. There are 36 distinct model IDs across the two tables; source decoration (medals) is retained verbatim in `model_raw`.
- **Metrics:** `judge_score` is the site's “Judge Scores on Open Questions”; values are copied as shown, in score points on a 0–100 scale. `accuracy` is the site's “Accuracy on Multiple-Choice Questions”; values are copied as shown in percent. Higher is better for both. The public dataset card identifies an ensemble LLM-as-a-Judge refresh for open questions; the paper reports the open-question judge approach uses an ensemble and validates it against legal experts. No per-model confidence interval, sample count, test date, cost, time, or reasoning-effort setting is shown in these leaderboard tables, so those fields are null.
- **Caveats:** These are benchmark-author-published results, recorded under the collection's `independent` reporter label. Open-question scores depend on LLM judges, despite the reported human-expert validation. The published results are stale relative to this capture date: the only explicit result refresh is 2025/09. Model names are preserved from the page; canonical IDs are best-effort mappings and do not assert exact provider API/version identifiers. The site does not report costs, runtime, or effort settings.
- **License:** The Hugging Face dataset card tags the dataset CC BY 4.0, and the repository's `LICENSE_DATA` is the Creative Commons Attribution 4.0 International license. The leaderboard page does not state separate redistribution terms; see the raw license file.
- **Not captured:** No additional current results beyond the two published HTML leaderboard tables were available from the referenced JavaScript endpoints. The raw directory preserves the page, dataset card, API metadata, and repository license evidence.

## Verification

- Parsed all 67 JSONL lines; each is an object with all 24 fields listed in `examples/model-bench/SCHEMA.md`, and the required and nullable field types are valid.
- Compared every row's subset, exact source model label, metric, and value against the two tables in `raw/lexam/leaderboard.html`: 36 open-question and 31 multiple-choice entries. All 67 matched; none were missing, extra, or value-mismatched.
- Explicit spot-checks included the three highest-scoring rows (GPT-5 70.20, Gemini-2.5-Pro 67.40, Claude-3.7-Sonnet 62.86) and rows 4, 12, 20, 32, 37, 38, 39, 48, and 60 of `rows.jsonl`; each label and value matches its source table. The full-table comparison also covers the remaining rows.
- The source has 38 distinct printed labels because GPT-5, Gemini-2.5-Pro, and Claude-3.7-Sonnet appear with different medal decorations across the tables; after removing those decorations it lists 36 models, matching the 36 distinct `model_id` values.
- No listed model is known to have been released during 2026-08-22 through 2026-09-22, so no extra recent-release spot-check applied. For example, official release notices date GPT-5 to 2025-08-07, Claude Sonnet 4.5 to 2025-09-29, and DeepSeek-V3.2 to 2026-04. These release dates are only a screen for the one-month criterion; all score checks use the captured LEXam tables.
- No data rows needed correction, addition, or deletion.
