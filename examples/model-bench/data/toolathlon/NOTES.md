# Toolathlon results

- **What it measures:** Toolathlon evaluates language agents on realistic, long-horizon task execution across diverse tools and software environments. The current release is **Toolathlon-Verified**, whose authors describe the tasks, ground truths, and evaluators as reviewed and aligned for the final release.
- **Data captured:** The site leaderboard table currently contains seven configurations. Its newest dated entry is 2026-08-30; this is the data date used for this capture. Per-entry dates are retained in `measured_on`. Retrieved 2026-09-23 UTC.
- **How captured:** Downloaded the live benchmark site HTML directly from https://toolathlon.xyz/ and extracted the published performance table. The exact table fields are preserved in `raw/toolathlon/leaderboard-table.json`; the full HTML snapshot is `raw/toolathlon/website.html`. Also captured the repository README and tree and the Hugging Face dataset API metadata. The current site table includes seven model configurations: all publish Pass@1, while five have values for the other four columns. Five configurations publish all five metrics and two publish only Pass@1, producing 27 rows: seven Pass@1 rows plus five configurations times four additional metrics.
- **Metric definitions:** Pass@1, Pass@3, and Pass^3 are reproduced as labeled by the site and treated as success-rate percentages; the captured table does not define their precise aggregation. Pass@1's displayed ± value is copied to `ci` as percentage points. “# Turns” and “# Tool Calls” are table averages; the site explains that turns count sequential rounds, a turn can contain multiple parallel tool actions, and both averages are computed over runs with valid trajectories. Lower is better for these two metrics.
- **Reporter and caveats:** The leaderboard marks listed entries with a check and tooltip “Evaluated by us,” so rows are labeled independent. Model dates vary from June 30 to August 30, 2026; the table does not establish that all entries were rerun on the same date or with identical conditions. Two configurations show em dashes for Pass@3, Pass^3, turns, and calls; no values were inferred. The page provides no sample counts. All displayed configurations use the “Default” agent. Model identity and effort are taken from the displayed names; canonical IDs are best-effort mappings.
- **License and redistribution:** No license was found in the GitHub repository tree or Hugging Face dataset metadata. The trajectory dataset is marked automatically gated and contamination-sensitive; its access text permits evaluation, reproducibility, auditing, and error analysis and forbids public mirroring or redistribution of raw trajectories. This capture contains only public leaderboard summaries and metadata, not trajectory files. No separate license for redistributing leaderboard values was stated.
- **Not captured:** The leaderboard page exposes no dollar cost, wall-clock time, per-task sample count, or further reasoning-effort variants. No numerical values were captured from gated trajectory archives.
