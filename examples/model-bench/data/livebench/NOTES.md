# LiveBench results capture

- **What it measures:** LiveBench publishes objectively scored language-model results on refreshed tasks spanning reasoning, math, coding (including agentic coding), data analysis, language, and instruction following. The captured release contains 23 task-level score columns grouped into seven leaderboard categories.
- **Data version/date:** Release `2026-06-25`, the newest release selectable by the live leaderboard at retrieval on 2026-09-23 UTC. The page says releases are refreshed every six months; the supplied manifest's monthly cadence is not what the current page states.
- **Collection:** Read the live leaderboard HTML and JavaScript to identify release selector and its raw files, then downloaded `table_2026_06_25.csv`, `categories_2026_06_25.json`, and `cost_2026_06_25.csv`. The exact files, page, app bundle, repository README/changelog/tree, and repository license are in `raw/livebench/`. The source table includes all listed model configurations; the output contains one row per model configuration per task-score column. It does not add page-computed category or overall aggregates as extra rows.
- **Metrics:** Each task column is an exact percentage score (`%`, higher is better). The task slug is retained as the metric. `n` uses the paired `nq_<task>` value where published. `cost_usd` uses the corresponding task's `cost_per_question` value and is on the same score row with `cost_basis: per_task`; it is the task question's evaluation cost, not the separately derived cost per successful task. No runtime or confidence interval is published in these files. Null means the source did not provide the field.
- **Model identity:** `model_raw` preserves the exact CSV label. `model_id` is a lowercase canonical guess; configuration effort suffixes are retained in `model_raw` and put in `effort` when explicitly encoded. For task categories that do not exactly match the shared schema, LiveBench Data Analysis is mapped to `knowledge-work`, and Language to `writing`.
- **Caveats:** The leaderboard describes LiveBench as contamination-free, but this capture does not independently verify contamination controls. Scores are independent benchmark results, though evaluation settings can differ by model and the published table gives no confidence intervals. Historical/stale model entries remain in the current release table as published. The page's current app metadata includes model display mappings; unknown/unmapped source model aliases are retained rather than discarded.
- **License/redistribution:** The GitHub repository carries Apache-2.0 (`raw/livebench/repository-LICENSE`). No separate license for leaderboard result data was stated in the files or page inspected; do not assume the repository code license independently grants rights to the data.
- **Limitations:** The table exposes task-level scores, not raw per-answer outcomes. The leaderboard's overall and category means are derived in the page; they are omitted here so values are not recomputed. There are no published time or reasoning-effort sweeps beyond effort labels included in model configuration names.
