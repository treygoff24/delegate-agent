# IFBench collection notes

- **What it measures:** Artificial Analysis describes IFBench as precise instruction-following generalization on 58 diverse, verifiable out-of-domain constraints. AA says its evaluations are conducted independently. This is IFBench, not IFEval.
- **Captured:** 2026-09-22 (page retrieved at 2026-09-23 01:12 UTC, which was still 2026-09-22 in the collection timezone, America/New_York). The page did not expose a separate score publication date or a benchmark release/version, so `measured_on` and `benchmark_version` are null.
- **Source and method:** Downloaded the rendered-source HTML directly from <https://artificialanalysis.ai/evaluations/ifbench>. The source page marks its score table `9 of 450 models`; its embedded JSON-LD contains nine IFBench scores, nine cost breakdowns, and eight per-task time values. The API URL mentioned in public search results returned HTTP 401 without an API key, so the public page's embedded structured data was used. The untouched downloaded page and extracted JSON-LD are in `raw/ifbench/`.
- **Metric:** AA publishes IFBench as a fraction from 0 to 1 in structured data, while the leaderboard displays percent. `value` converts the source fraction to percent (fraction × 100), with no rounding. Higher is better. Rows use `accuracy` as the shared-format metric name.
- **Cost:** AA publishes per-task input, cache-hit, cache-write, reasoning, and answer cost components. `cost_usd` is their arithmetic sum for the same configuration, in USD per task; no component was estimated. Cost values are retained at the precision implied by the source numbers.
- **Time:** AA describes its chart as weighted average decode time in minutes per task, excluding TTFT and overhead. The eight source values were converted from minutes to seconds for `time_s`; time is null for Grok 4.20 0309, which has no time entry in the published structured data.
- **Coverage/count:** 9 rows for 9 distinct model configurations, one IFBench score metric per configuration. The source page says it covers 9 of 450 models; the other 441 have no IFBench score shown on this page. Cost/time are paired fields, not additional metric rows.
- **Effort/configuration:** Effort is populated only where the source label states low, medium, high, or max. Other distinctions remain verbatim in `model_raw`; no unstated effort was inferred.
- **Caveats:** Results are independent AA runs, but individual run dates, confidence intervals, sample counts, and harness details are not exposed in the captured data. Leaderboard results may become stale as the continuously updated source changes. The AA page explains the task collection but provides no per-model protocol disclosure in this payload. Scores on IFEval are not interchangeable with IFBench.
- **Terms:** The page's structured data links its license field to the [Artificial Analysis Terms of Use](https://artificialanalysis.ai/docs/legal/Terms-of-Use.pdf). No separate open redistribution license for the leaderboard data was stated; treat the captured data as subject to those terms.
- **Uncaptured:** The API endpoint `https://artificialanalysis.ai/api/v2/data/llms/models` returned HTTP 401. The public page was sufficient for the nine configurations it exposes, but no broader API dataset or individual run-level results were accessible without credentials.
