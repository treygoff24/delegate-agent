# WebDev Arena collection

## What it measures

WebDev Arena (now presented as Code Arena / WebDev on Arena) compares interactive web apps generated by two models from the same user prompt. People vote blind on which result is better. Arena describes the rating as an Elo-like leaderboard built from pairwise comparisons; the benchmark's original write-up describes Bradley–Terry estimation. The board is a measure of crowd preference for generated web apps, not a direct functional correctness test.

No model effort settings are distinguished in this table.

## Fields and metric definitions

Each row records the source's displayed Arena score as `elo` in `elo` units, where higher is better. `n` is the leaderboard's displayed vote count. The source displays a 95% confidence interval and rank spread; exact interval text and rank/spread are preserved in `notes`. The interval is not represented in `ci` because the schema's single scalar cannot express the source's separate upper and lower bounds. Model names are copied from the source's model-name titles; `model_id` is a best-effort vendor/model normalization.

The page also displays model provider licensing, context length, and input/output API prices. Those are model metadata, not paired per-task cost or benchmark time, so they are not entered as score-row cost/time fields. The source publishes no per-task runtime or effort setting on this leaderboard.

## Caveats and terms

- This is a live, community-voted leaderboard; results can change as votes arrive. The captured page provides no score production date, so the retrieval time should not be mistaken for a measured-on date.
- Ratings are crowd preferences and can reflect prompt mix, sample-vote concentration, and participation effects. The original WebDev Arena article discusses deduplicating repeated sample prompts; this live page does not provide enough detail to reconstruct that adjustment for the captured ratings.
- The source's own preliminary label is retained in row notes where shown. No score was inferred or imputed.
- We found no redistribution license or data-specific license statement on the leaderboard page or its linked benchmark description. Row `license` is null; the displayed model license names are not data licenses.
- This capture includes every entry in the single overall WebDev table returned by the page. It does not include other Arena categories or historical snapshots.

## Method

Fetched the official leaderboard URL with `curl -L` and retained the returned HTML. Parsed the server-rendered leaderboard table, preserving one row for each listed entry and its score, vote count, interval, rank, and rank spread. All normalized fields were checked for JSON validity and schema-field presence.
