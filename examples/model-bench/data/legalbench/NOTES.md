# LegalBench results capture

- **What it measures:** Vals AI's leaderboard for LegalBench, a broad collection of legal reasoning tasks. The underlying LegalBench project describes 162 tasks contributed by legal practitioners and researchers. Results cover overall accuracy and five task groups: issue, rule, conclusion, interpretation, and rhetoric. It is primarily a task-solving benchmark, not a test of safe legal advice or full legal drafting.
- **Captured benchmark version:** `1` (Vals page payload); Vals marks the benchmark updated **2026-09-22**. The source does not give a separate measurement date for each model result.
- **Capture method:** Downloaded the Vals leaderboard page directly at <https://www.vals.ai/benchmarks/legal_bench> and retained the complete HTML page and its embedded structured leaderboard payload at `examples/model-bench/raw/legalbench/vals_legalbench_2026-09-22.html`. Rows use the payload's detailed per-configuration records. The model key is kept verbatim in `model_raw`; `model_id` is a lowercase canonical guess, mapping obvious inference-provider prefixes to the model publisher where clear.
- **Coverage/count:** 147 configurations have a score in each of the six reported subsets, producing 882 rows (147 configurations × 6 accuracy subsets). Cost and latency are paired fields on each accuracy row, not separate metric rows. Source lists 147 configurations in its metadata; no model configurations were omitted.
- **Metric definitions:** `accuracy` values are copied in the source's percent unit without conversion; higher is better. The source's `stderr` is copied to `ci` as the stated error (the source does not define its construction in the captured payload). `cost_per_test` is copied to `cost_usd` with basis `per_task`; `latency` is copied to `time_s`; its basis is null because the payload does not define whether it is per task or total wall time. Missing paired values remain null. Effort is copied from `reasoning_effort` where provided; source configurations without an explicit effort retain null.
- **Caveats:** Vals runs and reports the evaluations; results are third-party benchmark results and are not independently reproduced here. The leaderboard includes older model generations alongside current models; the source payload does not expose an individual result date, so the page update date should not be read as the run date for every score. Aggregate accuracy hides differences across task types and does not establish legal reliability, jurisdictional coverage, or suitability for client advice. No cost or latency was inferred when the payload omitted it.
- **License/redistribution:** The LegalBench repository says its datasets combine created and transformed data and asks users to follow each dataset creator's license; see <https://github.com/HazyResearch/legalbench>. The Vals leaderboard page's captured payload states no separate license or redistribution terms for the results. The `license` fields therefore remain null.
- **Not captured:** No per-model run dates, sample counts, raw model responses, or separately defined confidence-interval method were available in the leaderboard payload. No task-level scores below the five aggregate task groups were included in the published page payload.
