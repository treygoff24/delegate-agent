# FrontierSWE V2 collection notes

- **Benchmark:** FrontierSWE V2 evaluates agents on 34 long-horizon software engineering, research, and technical tasks. The website says each model gets five trials per task with a 20-hour budget, using the Proximus harness.
- **Version and capture date:** V2; captured September 22, 2026 local time (retrieved 2026-09-23T01:17:06Z UTC). The V2 announcement is dated September 2026, but source tables give no exact run date, so `measured_on` is null.
- **Collection method:** Saved the [live homepage](https://www.frontierswe.com/), [V2 announcement](https://www.frontierswe.com/blog/v2), and [public task repository](https://github.com/Proximal-Labs/frontier-swe-v2); read the task/result payload embedded in the homepage and saved all 34 linked task-result pages. Task page values are the source for per-task metrics; the live homepage leaderboard was captured separately as `overall`. The launch announcement table differs from the current homepage and was not treated as current aggregate data.
- **Configurations and rows:** 16 distinct canonical model IDs, evaluated with `proximus`; no reasoning-effort variants are stated. Each task page has 16 model rows. There are 34 × 16 × 4 = 2,176 task rows (score, steps, input tokens, output tokens), plus 10 current overall `mean@5` rows, for 2186 total. Score rows carry paired task-average cost and time. Overall rows carry aggregate score and displayed per-trial average cost/time.
- **Metric definitions:** Task `score` values are copied from displayed 0–1 scores; `ci` is the displayed ± half-width, with no further interpretation. Steps and input/output tokens are source-reported means across five trials. Source token suffixes k/M were converted using decimal multipliers. Task times were converted from displayed hours/minutes to seconds. The homepage defines `mean@5` as the mean across 34 tasks, and says cost/time are per-trial averages. `n` is five for task rows and 34 tasks for the aggregate score.
- **Caveats:** The benchmark owner runs these evaluations on its Proximus harness; the supplied manifest classifies the reporter as independent. The V2 post describes per-trial cheating-attempt audits, but this collection did not reproduce runs or inspect linked traces. Tasks are public in the GitHub repository, so task-content exposure is possible; the source does not quantify contamination. No exact run date is published. The original launch-post table is stale relative to the current homepage leaderboard.
- **License/redistribution:** The repository README says task content and test harnesses are provided for evaluation and points to task directories for upstream attribution. No explicit license or redistribution grant for leaderboard results was found; this capture does not claim one.
- **Not captured:** Individual trace contents and per-trial records were not downloaded. Task pages expose model-level means, displayed intervals, and average usage/cost/time. No effort settings are published.

## Verification

- Checked all 2,186 JSONL lines: each parses and contains exactly the 24 schema fields, with values of the declared types.
- Spot-checked 10 records against their matching captured task tables. All matched: the three highest `score` rows (Claude Fable 5.1 and Claude Opus 5.5 on Lean Checker Pascal; Claude Opus 5 on Lua Native Compiler), additional task scores for recent releases GPT-6 Astra, Gemini 3.8 Flash, and Grok 4.7, and representative input-token, output-token, and step rows. Compared score, interval, paired cost, and paired time where present. The recent-release models are dated September 1–22, 2026 in their respective official announcements.
- Checked source coverage across all 34 captured task pages: each lists 16 model rows, and each page's raw model spellings match the 16 collected score rows with exactly four metrics per model. The source uses 18 spellings across the full set, including asterisk variants; these map to 16 canonical model IDs in the rows. All 10 homepage aggregate model labels and `mean@5` values match the 10 aggregate rows.
- **Changes:** none. No mismatch, missing row, or extra row was found in the checks.
