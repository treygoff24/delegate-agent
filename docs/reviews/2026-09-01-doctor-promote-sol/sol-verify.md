## New defects and misleading coverage introduced by the fix commit

1. **Docs/describe now contradict Claude workflow behavior.** Claude schemas are native after this commit, but `docs/delegate-workflows.md:218-223` still says optional fields and typed maps use prompt-and-parse like the other engines, and `src/delegate_agent/describe_payload.py:1065-1075` says the same. This is a behavior-documentation regression from changing runtime routing without updating its public contract.
2. **The doctor read-only test passes while doctor creates a file.** It snapshots only `active-supervisors.json`; it never checks the home tree or `.active-supervisors.json.lock` (`tests/test_workflow_pinning.py:424-447`).
3. **The promotion race test misses the original pre-lock window.** It verifies a writer waits on an already-held lock, but never pauses after the default runtime digest is captured and before lock acquisition (`tests/test_workflow_pinning.py:466-498`).
4. **The launcher test manufactures a digest mismatch.** It proves warning formatting, not detection through the installed shell shim, console script, or `python -m` (`tests/test_workflow_pinning.py:449-464`).
5. **The Claude workflow test covers one permissive object only.** It does not compare `validate_schema_subset` with Claude's own JSON-Schema validator, so accepted-but-launch-rejected enum/required/type shapes stay green (`tests/test_workflow_retry_outcomes.py:276-322`).

I found no additional source regression beyond those incomplete fixes and the stale workflow-schema docs.
